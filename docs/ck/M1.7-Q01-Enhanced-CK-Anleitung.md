## A. Grundgriffe im CK (einmal lesen)

| Aufgabe | Wo / Wie |
|---|---|
| Objekt suchen | **Object Window** (links). Oben das Feld **Filter**: Text eingeben, filtert nach EditorID und Name. Baum links wählt die Kategorie. |
| Objekt platzieren | Object Window: Eintrag anklicken und **ins Render Window ziehen** (Drag & Drop). |
| Zelle öffnen | Menü **World → Cell View** (Fenster „Cell View“). Oben **World Space: Tamriel**. Für Außenzellen: die Felder **X** und **Y** (Zellkoordinate) eingeben oder in der Zellliste suchen, Doppelklick auf die Zelle lädt sie ins Render Window. |
| Ref bearbeiten | **Doppelklick auf das Objekt im Render Window** → Dialog „Reference“. Dort: **EditorID** (oben), Haken **Persistent Reference**, Haken **Initially Disabled**, Reiter **3D Data** (Position/Rotation). |
| Ref verschieben | anklicken, dann Gizmo ziehen oder im Dialog → **3D Data** Werte eintragen. Taste **F** setzt ein Objekt auf den Boden. |
| Position ablesen | Ref-Dialog → **3D Data** oder im Spiel mit `getpos x/y/z`. |
| Persistent | Nur nötig, wo unten „persistent“ steht (Script-Properties, Marker, NPCs). Ohne EditorID erscheint die Ref nicht in der Property-Auswahl. |
| Kopie eines Vanilla-Objekts | Object Window: Rechtsklick → **Duplicate**; im sich öffnenden Dialog sofort **EditorID** ändern und mit OK bestätigen. Nie das Original speichern. |

## 2. Reedbed (Location A)

**Wo:** Sumpf in Hjaalmarch, Fußweg von Morthal 1–2 Minuten, abseits der Straße. Vorschlag zur Orientierung: Hakans Steg liegt in Zelle (-9 / 16); das Camp liegt etwa in (-7 / 17). Lege das Reedbed in eine andere Richtung (z. B. Zelle (-10 / 17) oder (-9 / 18)) auf eine kleine Sumpfinsel. Fest vorgegeben ist nur: **alle drei Scavenger in derselben Zelle, in Sichtweite voneinander (unter 600 Einheiten)**.

1. **Zelle laden:** Cell View → Tamriel → Zelle wählen → Doppelklick.
2. **Szenerie (Dressing):** aus B.2 je 1 Lagerfeuer, 2 Bedrolls, 1 Zelt, 1 Fass ziehen. Kein Dressing im Wasser.
3. **Sack mit dem Marker:**
   - Object Window → **WorldObjects → Container** → Filter `MiscSackLargeFlat01_NoRespawn` → Rechtsklick → **Duplicate**.
   - Im Dialog: **EditorID** `NHV_Cont_Q01_ReedbedSack`, Name „Sack“ (oder „Scavenger's Sack“).
   - Im selben Dialog die Inventarliste: **Add** → `NHV_Item_Q01_RedFerryMarker` **Count 1**.
   - Den Haken **Respawns** (falls vorhanden) **ausschalten**.
   - OK. Dann den neuen Container ins Render Window am Lagerfeuer ziehen. Ref: Ownership leer.
4. **Drei Scavenger:** Object Window → **Actors → Actor** (in deiner Version: Character → NPC, dort zeigt der Filter `NHV_Q01_MarshScavenger`) → 3× ins Render Window ziehen, sitzend/stehend um das Feuer. Bei jedem (Doppelklick): **EditorID** `NHV_Ref_Q01_Scav01`, `…Scav02`, `…Scav03`; Haken **Persistent Reference**; Initially Disabled **aus**.
5. **AI:** Doppelklick auf den Base-NPC `NHV_Q01_MarshScavenger` (im Object Window) → Reiter **AI Packages**. Dort steht bereits 1 Package (prüfen: Sandbox; Vorschlag `DefaultSandboxCurrentLocation256`, Vanilla, FormID `0956B8`). Aggression bleibt **Unaggressive**. Sie werden erst per Script feindlich (`ReedbedHostile()`), nachdem das Gespräch zu Ende ist.
6. **Navmesh:** Falls im Lager keiner liegt (Render Window → Navmesh-Ansicht, Menü **View**), nur kleinen Bereich (Radius ca. 800) nachziehen. Kein Vanilla-Navmesh löschen.
7. Zelle und Koordinaten der Scavenger-Refs an Claude melden (für ARCHITECTURE.md).

**Optional (kosmetisch, Quest läuft auch ohne):**
- **Location:** World Data → Location → Rechtsklick New → EditorID `NHV_Q01_ReedbedLocation`, Name „Reedbed“, Parent `MorthalLocation`, Keyword `LocTypeBanditCamp`. **Sie muss keiner Zelle oder Ref zugewiesen werden**; kein Script nutzt sie.
- **Encounter Zone:** World Data → Encounter Zone → New → `NHV_Q01_ReedbedEZ` (Never Resets an). Zuweisung nur, wenn dein Ref-Dialog ein Feld „Encounter Zone“ hat (bei den Scavengern und beim Sack). Fehlt das Feld: weglassen.
