## Schritte

### 1. Vor dem ersten Öffnen prüfen

1. Object Window → Quest → `NHV_Q01_TheUnansweredSacrament` (004000) doppelklicken → Reiter **Quest
   Data**: Priority muss `90` sein (wie Q00), Haken **Start Game Enabled** muss **leer** sein (Q01
   startet über `NHV_CoreScript.StartQ01()` am Ende von Q00).
2. **„Complete Quest“ setzen:** Reiter **Quest Stages** → Stage `100` markieren → im Log-Entry darunter
   (Eintrag „Return to Veyra.“) den Haken **„Complete Quest“** setzen. Das markiert Q01 nur im Journal als
   erledigt; die Quest läuft weiter, der 7-Tage-Brief (Ausgang „Release“) kommt also an.
   **Kein** „Shut Down Quest“ setzen (Team-Lead-Klärung 28.09.2026, Script-Kommentar angepasst).
3. Für Zwischentests ohne kompletten Q00-Durchlauf per Konsole: `setstage NHV_Q01_TheUnansweredSacrament 10`
   (EditorID, nicht die Laufzeit-FormID – `setstage 004000 10` funktioniert nicht, weil die
   Runtime-FormID den Load-Order-Präfix braucht) oder `cqf NHV_Sys_Core StartQ01`. Zur Kontrolle
   `sqv NHV_Q01_TheUnansweredSacrament` (aktuelle Stage) bzw. `sqs NHV_Q01_TheUnansweredSacrament`
   (alle Stages mit Erledigt-Status) nutzen.
