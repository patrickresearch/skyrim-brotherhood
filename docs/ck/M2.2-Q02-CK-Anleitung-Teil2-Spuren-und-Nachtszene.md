# M2.2 – Q02 „Cold Waters“: CK-Anleitung Teil 2 (Spuren und Nachtszene)

Stand: 30.09.2026. Ergänzt `docs/ck/M2.2-Q02-CK-Anleitung.md`. Laut Rückmeldung des Entwicklers sind fertig:
NPCs (Abschnitt 1), alle Platzierungen in `WindhelmDocksExterior01` außer den Spuren (Abschnitt 2), beide Interiors
(3.1, 3.2) und die Quest-Properties (Abschnitt 4). Hier folgen die restlichen Punkte: **A** „Latest Victim“,
**B** Track Clues 1–3, **C** Nachtszene Stage 30, **D** Sings’ Weg zur Hollow (Stage 40).

**Ein-Schreiber-Regel (E17):** ESP im CK öffnen, alles unten erledigen, **einmal** speichern, CK schließen, dann melden.
Claude macht danach `tools\plugin_text.ps1 -Direction ToText`.

---

## Vorab: Warum die Aktivatoren nicht einfach platzierbar sind

Die vier Aktivator-Records (`NHV_Act_Q02_LatestVictim`, `…TrackClue1/2/3`) haben als Platzhalter-Modell die
**Waffen-Wandtafel** (`Clutter\WeaponRack\WRPlaque01.nif`). So platziert, hängt am Pier eine Holztafel. Deshalb:

- **Latest Victim:** kein Aktivator, sondern eine **Leiche mit dem Script direkt an der Referenz** (A).
- **Track Clues:** Aktivatoren behalten, aber **Modell tauschen** (B).

Der Base-Record `NHV_Act_Q02_LatestVictim` bleibt dabei ungenutzt im Plugin. **Nicht löschen** (Regel 3, FormID bleibt).

## A. „Latest Victim“: Leiche am Ostpier (Stage 10 → 20)

### A1. Leichen-NPC anlegen (eigener Record)
1. Object Window → Actors → Actor → Rechtsklick auf `NHV_HaldorFrostKnuckle` → **Duplicate**.
2. Das Duplikat öffnen: EditorID `NHV_Q02_VictimCorpse`, Name `Dockworker`.
3. Reiter **AI Packages**: alle Einträge entfernen. Reiter **Factions**: alle entfernen.
4. Reiter **Inventory**: einfache Arbeitskleidung, keine Waffen, kein Gold (sonst plündert der Spieler Beute).
5. Reiter **Traits**: Voice Type egal (spricht nie). „Essential“/„Protected“ aus.
6. Gesicht leicht ändern (sonst Haldors Zwilling), dann im Preview **Strg+F4** (FaceGen). OK.

### A2. Leiche platzieren
1. `NHV_Q02_VictimCorpse` per Drag & Drop an den Ostpier ziehen (Nähe Torbjorn, gut sichtbar, am Wasserrand).
2. Doppelklick auf die Referenz → Reiter **3D Data/Base**: EditorID `NHV_Q02_VictimCorpseRef`.
3. Haken **Starts Dead** setzen. (Die Pose ergibt sich erst im Spiel als Ragdoll; die Leiche möglichst auf ebenen
   Boden setzen, nicht an die Kante, sonst rutscht sie ins Wasser.)
4. Haken **Persistent** setzen.

### A3. Script an die Leichen-Referenz
Im selben Reference-Dialog → Reiter **Scripts** → **Add** → `NHV_Q02_StageActivatorScript` → Properties:

| Property | Wert |
|---|---|
| `OwningQuest` | `NHV_Q02_ColdWaters` |
| `NHV_Cfg_Debug` | `NHV_Cfg_Debug` |
| `RequiredStage` | `10` |
| `TargetStage` | `20` |
| `ClueMessage` | leer |

Ergebnis im Spiel: Der Spieler „durchsucht“ die Leiche (Loot-Menü öffnet sich, bleibt leer) und die Quest springt
auf 20. Vor Stage 10 und nach Stage 20 passiert nichts.

## B. Track Clues 1–3 (Stage 40, Pfad B)

### B1. Modell tauschen (einmal je Base-Record, drei Records)
1. Object Window → WorldObjects → Activator → `NHV_Act_Q02_TrackClue1` öffnen.
2. Feld **Model** → **Edit** → ein Mesh wählen, das **Kollision** hat (sonst lässt es sich nicht per Fadenkreuz
   aktivieren). Passend sind z. B. Seil, Fischernetz, Knochen, Stofffetzen, Holzplanke.
   So findest du den Pfad sicher: Object Window → Filter „Rope“, „Net“ oder „Bone“ bei **Static** oder **MiscItem**,
   Record öffnen, den Modellpfad kopieren und hier einfügen.
3. Optional **Activate Text Override** auf `Examine` setzen; dann zeigt das Spiel „Examine“ statt „Activate“.
4. Script und Properties am Record **nicht anfassen**; sie sind schon gesetzt (Clue 1/2: nur Nachricht; Clue 3:
   Nachricht und Stage 50).
5. Gleiches für `…TrackClue2` und `…TrackClue3`. Gern drei verschiedene Meshes.

### B2. Platzieren (in `WindhelmDocksExterior01`)
Eine Spur, die dem Wasser folgt, vom Nachtszenen-Ort zum Hollow-Eingang:

| Referenz-EditorID | Base | Wo |
|---|---|---|
| `NHV_Q02_TrackClue1Ref` | `NHV_Act_Q02_TrackClue1` | 5–10 m vom `NHV_Mk_Q02_DockWatch`, an den alten Pfählen (Text: „The water carried him toward the old pilings.“) |
| `NHV_Q02_TrackClue2Ref` | `NHV_Act_Q02_TrackClue2` | unterer Steg, dort wo die Flut beginnt (Text: „The footprints stop where the tide begins.“) |
| `NHV_Q02_TrackClue3Ref` | `NHV_Act_Q02_TrackClue3` | 3–5 m vor der Ladetür `NHV_Q02_DrownedHollowDoorExt` |

- Kein „Persistent“ nötig, kein „Initially Disabled“.
- Jede Spur muss vom Spieler **zu Fuß erreichbar** sein (Navmesh in der Nähe vorhanden). Bestehendes Navmesh nicht ändern.
- Die Reihenfolge wird nicht erzwungen. Nur Clue 3 setzt Stage 50; deshalb Clue 3 räumlich zuletzt.

## C. Nachtszene Stage 30 (`NHV_Scn_Q02_01HaldorDocks`)

Was das Script tut: Ab Stage 30 prüft `NHV_Q02Script`, ob es zwischen **22:00 und 04:00** ist und der Spieler
**≤ 1200 Einheiten** von `NHV_Mk_Q02_DockWatch` steht. Dann startet die Szene (ohne Cutscene-Sperre, der Spieler kann
eingreifen). Phase 1: Haldor schikaniert (030_01/02). Phase 2: „Something’s got my leg!“ (030_03) oder, wenn der
Spieler Sings angegriffen hat, „Something pulled me under! Guards!“ (030_10). Szenenende → Stage 40.

### C1. Haldor und Sings an den richtigen Ort
- **Haldor** steht laut Rückmeldung am Szenenort. Prüfen: Abstand `NHV_HaldorFrostKnuckleRef` ↔ `NHV_Mk_Q02_DockWatch`
  höchstens 5–8 m, beide am Wasserrand.
- **Neuer Marker** `NHV_Mk_Q02_SingsWater` (Base `XMarkerHeading`) **im Wasser**, 2–3 m von Haldor, Blickrichtung zu Haldor.
  Im Ref-Dialog EditorID setzen, **Persistent**.

### C2. Package für Sings (neuer Record)
1. Object Window → Character → Package → Rechtsklick → **New**. EditorID `NHV_Pkg_Q02_SingsNightHunt`.
2. Template **Travel**. Unter **Place to Travel**: *Near Reference* → Ref `NHV_Mk_Q02_SingsWater`, Radius 0.
3. Flags: **Preferred Speed** = Walk. Keine Conditions (die Szene steuert es).
4. OK.

### C3. Package in die Szene einhängen
1. Szenen sind kein eigener Objekttyp, sie hängen an der Quest: Object Window → Character → **Quest** →
   `NHV_Q02_ColdWaters` → Reiter **Scenes** → links `NHV_Scn_Q02_01HaldorDocks` anklicken.
2. Die Actors (Sings = Alias 2, Haldor = Alias 5) sind schon eingetragen. Aktionen `HaldorHarass` (Phase 1) und
   `HaldorPull` (Phase 2) nicht ändern.
3. Rechtsklick in die Zeitleisten-Zeile von **Sings** → **New Package**.
   - Start Phase **1**, End Phase **2** (Sings bleibt die ganze Szene im Wasser).
   - Packages: `NHV_Pkg_Q02_SingsNightHunt` hinzufügen.
4. **Actor-Flags von Sings:** Doppelklick auf Sings in der Actor-Liste links (ggf. Rechtsklick → Edit) → im Dialog
   mit Death/Combat/Dialogue Pause/End **„Combat End“ abwählen.** „Death End“ bleibt gesetzt.
   Grund: Wenn der Spieler Sings angreift und die Szene dabei abbricht, läuft Haldors Rettungszeile 030_10 nie, und
   die Quest kann fälschlich in Pfad A (Beschatten) landen statt in Pfad B (Spurensuche).
5. OK, Szene speichern.

### C4. Optional: Sings flieht statt zu kämpfen
Greift der Spieler Sings an, kämpft Sings sonst zurück. Wenn Sings fliehen soll: NPC `NHV_SingsBeneathIce` → Reiter
**AI Data** → Confidence **Cowardly**. **Nur setzen, wenn das nach der Rekrutierung nicht stört** (als Follower
flieht ein „Cowardly“-NPC vor Kämpfen). Im Zweifel weglassen und melden, dann baut Claude eine Script-Lösung.

## D. Sings’ Weg zur Hollow (Stage 40)

Ohne Package steht Sings nach der Szene still, und das Beschatten (Pfad A) hat nichts zu beschatten. Ein Travel-Package
mit Ziel **in** der Hollow reicht für beide Pfade: Sings läuft selbst durch die Ladetür.

### D1. Packages anlegen
1. Neues Package `NHV_Pkg_Q02_SingsToHollow`: Template **Travel**, Place to Travel *Near Reference* →
   `NHV_Mk_Q02_SingsHollow` (der Marker in `NHV_Q02_DrownedHollowCell`), Radius 128. Preferred Speed **Walk**.
   Conditions (Reiter Conditions, Run On *Subject*):
   - `GetStage` Quest `NHV_Q02_ColdWaters` `==` `40`
2. Neues Package `NHV_Pkg_Q02_SingsFleeHollow`: gleich, aber Preferred Speed **Run**. Conditions:
   - `GetStage` Quest `NHV_Q02_ColdWaters` `==` `40` **AND**
   - `GetGlobalValue` `NHV_Q02_HaldorSaved` `==` `1`

### D2. An den Sings-Alias hängen
1. Quest `NHV_Q02_ColdWaters` → Reiter **Quest Aliases** → Alias **Sings** (ID 2) doppelklicken.
2. Unten **Alias Package Data** → Rechtsklick → Add → erst `NHV_Pkg_Q02_SingsFleeHollow`, dann
   `NHV_Pkg_Q02_SingsToHollow`. **Reihenfolge wichtig:** Flee steht oben (wird zuerst geprüft).
3. Die vorhandenen ForceGreet-Packages (`SingsHollowGreet`, `SingsJudgeGreet`) nicht verändern; ihre Stage-Bedingungen
   (50, 70) überschneiden sich nicht mit Stage 40.
4. OK, Quest speichern.

### D3. Prüfen
- Die Hollow-Außentür `NHV_Q02_DrownedHollowDoorExt` hat das Script `NHV_Q02_StageActivatorScript` mit
  `RequiredStage` 40 / `TargetStage` 50 (aus Teil 1, Abschnitt 2). Sings’ eigenes Türbenutzen löst nichts aus; nur
  der Spieler setzt Stage 50.
- Navmesh: Weg von `NHV_Mk_Q02_SingsWater` bis zur Hollow-Tür muss durchgehend sein. Im Render-Window mit **Navmesh
  sichtbar** (M) abfahren; Lücke an der Ladetür = Sings bleibt stehen.

## E. Test (Save direkt nach Q01 oder `coc WindhelmDocksExterior01`)

Vorbereitung: `set NHV_Cfg_Debug to 1`, `startquest NHV_Q02_ColdWaters`, `setstage NHV_Q02_ColdWaters 10`.

| Schritt | Erwartung |
|---|---|
| Leiche durchsuchen (Stage 10) | Loot-Menü, Quest auf 20 |
| `setstage NHV_Q02_ColdWaters 30`, `set gamehour to 21.9`, zum DockWatch gehen | Um 22:00 läuft Sings zum Marker im Wasser, Haldor sagt 030_01/02, dann 030_03; Stage 40 |
| Pfad A (nicht eingreifen) | Sings geht (Walk) zur Hollow-Tür und hinein. Spieler folgt, benutzt die Tür → Stage 50 |
| Pfad B (neues Laden in Stage 30, Sings während der Szene angreifen) | Haldor sagt 030_10, Szene endet normal, Stage 40; Sings **rennt** zur Hollow. Clue 1/2 zeigen Nachrichten, Clue 3 setzt Stage 50 |
| Save/Load in Stage 30 vor 22:00 | Szene startet nach dem Laden trotzdem |

Log-Zeilen, die **nicht** kommen dürfen: `UpdateNightWatch: DockWatchMarker property not set`,
`StartHaldorDocksScene: Sings or Haldor unavailable`, `NHV_Q02_StageActivatorScript: OwningQuest not set`.
Zurückmelden: Papyrus-Log und ob in Pfad B die Zeile 030_10 kam.
